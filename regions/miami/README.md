# Miami region pack

Research sources and local guidance for Miami-Dade County, Florida. Select it with `"region": "miami"` in your `profile.json`.

- `research_sources.yaml`: official and secondary sources (flood, permits, elevators, crime, transit) shown in the dashboard source registry.
- `data_source_plan.md`, `source_gap_audit.md`, `source_guidance.md`: how to research a neighborhood or building here.

To add another city, copy this folder to `regions/<your-city>/` and replace the sources.
